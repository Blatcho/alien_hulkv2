# Hull Breach (working title)

A 2D side-scrolling squad roguelike for the browser. A four-trooper boarding team enters a procedurally generated derelict ship at the rear airlock and must reach the command deck at the bow.

You pick the four who go, their order and their standing orders before boarding. Once aboard, the marines run themselves, each according to their own stats, while predators hunt them through the vents, along the walls and across the ceilings.

There are no navigation buttons. In the mission you can:
- press **Cover** or **Turn around**;
- change the **standing orders** as the ship changes, from the orders bar;
- **point at things in the scene** (a door, ladder, crate, terminal, survivor or fuel barrel) to send the squad there;
- **choose at encounters**, which put choose-your-own-adventure options in the scene with the odds for whoever would do the job.

- **Rendering**: [three.js](https://threejs.org) (WebGL), side-on orthographic camera, post-processing.
- **Physics**: [Rapier 2D](https://rapier.rs) for line of sight, hitscan and debris.
- **Art**: generated by Python scripts in **Blender 5.2**, exported as skeletal **GLB**. There are no sprite sheets.
- **Audio**: recorded CC0 sound effects (Freesound, Kenney, OpenGameArt) over a procedural WebAudio fallback. See [Sound](#sound).

## Quick start

```bash
npm install
npm run dev          # http://localhost:5173  (asset viewer: /viewer.html, sound board: /sfx.html)
npm test             # generator, navigation, visibility and headless simulation tests
npm run assets       # rebuild all art in headless Blender (see tools/blender/README.md)
npm run build        # production bundle in dist/
```

### Deploying

Every push to `main` runs the tests, builds, and uploads `dist/` to Bluehost over FTPS ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)), where it is served at **https://blatcho.com/games/sotb/** (the FTP account's home folder is that `games/sotb` folder). It can also be run by hand from the Actions tab. It needs these repository secrets (Settings → Secrets and variables → Actions):

| Secret | Value |
|---|---|
| `FTP_SERVER` | FTP host, e.g. `ftp.example.com` |
| `FTP_USERNAME` | a dedicated cPanel FTP account, e.g. `deploy@example.com` |
| `FTP_PASSWORD` | that account's password |

Set the FTP account's directory to the folder the game should live in (e.g. `public_html/game`), and the deploy uploads to its root. If the account's home is somewhere else, set the repository **variable** `FTP_SERVER_DIR` to the path from there, ending in `/` (e.g. `public_html/game/`). The build uses relative paths, so the game runs from any folder.

Useful URL parameters:

| Parameter | Effect |
|---|---|
| `?brief=AB12CD` | Quick play: the briefing for ship AB12CD (pick 4 of its 8 candidates, set orders and difficulty). A bare seed rolls the hull class; `?brief=STN-AB12CD` names it (see [Hulls](#hulls-the-derelicts)), and the briefing's hull picker rewrites the code. |
| `?seed=AB12CD&go=1` | Quick play straight in. `&squad=c0,c3,c5,c6&doc=direct.normal.steady.way.critical.on` choose the squad and orders (`&pool=2` picks from the second rerolled set of candidates), and `&diff=many.tough.large.often` the difficulty (enemies, strength, ship size, hordes). With no `squad`, the four have baseline stats. |
| `&autoplay=1` | No player input: encounters resolve at once (tests and attract mode). |
| `&retro=0` | Full-resolution rendering instead of pixel mode (`&retro=1` forces pixel mode). Without it, the game uses the player's last choice (`P`), and pixel mode the first time. |
| `&debug=1` | Shows frame stats. |
| `&nofog=1` | Turns off fog-of-war. |
| `&god=1` | Makes the squad invulnerable. |
| `&sfx=synth` | Procedural sound only (no recorded effects). |

## Controls

| Key | Action | Key | Action |
|---|---|---|---|
| `C` | **Cover**: a full stop. Everyone crouches and nothing moves on until it is released. | `T` | **Turn around**: the rear man leads the way back. |
| `Q` | throw a **grenade** into the thick of them | `E` | pop a **flare** ahead of the point man |
| `D` | **Defend**: two sentry guns either side of the squad that stay and keep firing (one kit to start, more found aboard) | `K` | Kit order: use it or save it |
| `1`–`3` | choose at an encounter | `Space` | pause |
| `R` `F` `G` | next route, fire discipline, pace | `L` `H` `V` | next loot, stims, flashlights order |
| `Tab` | the **ship map**: the whole derelict deck by deck as the squad has seen it, the contract, what's been found and the ship's log; the run waits while it's open | `P` | pixel mode on/off (on by default) |
| `+` `-` | zoom (or the mouse wheel / trackpad scroll) | `` ` `` | debug stats |

| mouse | hover over a door, ladder, stairwell, crate, terminal, vent, door control, survivor, man down or fuel barrel the squad has seen, then click to send them | | |

(Squad mode. For a controller and one marine of your own, see **Lead mode** below. The **CONTROLS** button on the title and launch screens shows both tables.)

Everything you can click glows faintly in the scene, breathing slowly, so you can see it before the cursor finds it. The colour shows what it is:
- **Blue:** doors, ladders and stairs (dimmer for an open door), with a smaller pip for door controls and vents.
- **Amber:** crates and lockers with something left in them.
- **Green:** terminals and set pieces.
- **Gold:** survivors and distress calls.
- **Red:** a man down.
- **Orange:** fuel barrels and fires.

A glow appears only for rooms the squad knows, sits under the fog of war, and fades once the thing is done: searched, welded, rescued.

The bar at the bottom has three clusters. **ACT** is Cover, Turn back and the map. **KIT** shows what's left of the grenades, flares and Defend kits. **ORDERS** is the seven standing orders: click one to pick another option (or press its key to cycle it); the squad acknowledges and acts on it from then on. Fire carries the squad's energy meter, Pace its breath (the most winded trooper).

The rest of the HUD: each trooper's card top-left (name in his rank's colour, health, the magazine and reserve, breath, and a glyph for anything wrong - reloading, dry, panicking, a wound, down); the tracker top-right; a **ticker** top-centre that shows the last few lines of the ship's log (contacts, finds, doors welded, power failures, men down and back up - every notable thing, timed, the same log the map and the debrief show); and bottom-right the objective over a strip of meters: lifesigns (with an arrow when they've fallen lately), the ship's **danger** (how close the noise has brought it to calling its horde), energy, morale, stims and charges, a keycard and a sentry gun still firing. Only a man down or taken, the horde and the ship cleared still shout across the middle of the screen.

Everything else is handled by the marines themselves: doors, ladders, fights and loot by their orders.

### Lead mode: one marine on the controller

The briefing's **COMMAND** choice picks how a mission is run. **SQUAD** is the game above: the four run themselves by your standing orders and you point and click. **LEAD** puts you in one marine's boots: the first trooper you pick is you, up to three more follow you, and you walk, aim, shoot and use things yourself with an Xbox-style controller (or keys and mouse). Everything else is unchanged: the same ship, hostiles, encounters, kit, loot, wounds and campaign; the followers keep station behind you, shoot by their fire discipline, cover and stim you, search what you open and get you up when you go down (if you die, the next man in the line is yours).

| Controller | Action | Controller | Action |
|---|---|---|---|
| left stick | walk; all the way is a run (while you have breath); up or down at a ladder or stairwell takes it | right stick | aim (a hostile near your line draws the fire) |
| `RT` | fire, for as long as it's held | `LT` | cover: everyone crouches (slow, hard to hit) |
| `A` | use whatever you're standing at: a crate, a terminal, a sealed or locked door, the command console, a man down | `B` | the followers hold where they are / fall in behind you again |
| `X` `Y` `LB` | grenade, flare, defend | `RB` | reload |
| D-pad | the followers' orders (fire discipline, stims, lights, kit) - or an encounter's options, `A` to pick | `Start` `Back` | pause, the ship map |

Keyboard and mouse do the same: `WASD` / arrows walk, the mouse aims from your marine, mouse 1 fires, `Shift` cover, `E` use, `R` reload, `T` hold / follow, `Q` `F` `G` grenade, flare, defend, `X` `H` `V` `K` the followers' orders, `Tab` the map.

Open doors, obstacles to vault or duck under and the outer lock are taken in your stride; a plain sealed door opens when you walk into it; welded, burning and locked doors, crates, terminals and the console wait for `A`. A prompt in the scene shows what `A` would do, and the reticle turns red on the hostile your aim has locked onto. Quick play carries the choice as `&ctrl=lead`; a campaign remembers it between missions.

## The campaign (roguelike layer)

- **Launch** (aboard the Kestrel, between runs): one screen and one DEPLOY. The three derelicts on offer across the top; the troopers below as compact cards (rank, archetype, weapon, and the stats that stand out as chips - **CHIPS / BARS** switches to all eight); and beside them the **contract card** (the ship, its story, anomalies, what matters here, the objective and the pay), the **line-up** (the order you pick is the line: slot 1 walks point, slot 4 is the rear guard; click a slot or drag a card to move up) with who will be the tech and medic, who has the sharpest eyes, who sets the pace and who tires first, the **COMMAND** choice (Squad or Lead), and the run's **settings** folded into one line of chips (the standing orders and the difficulty, remembered from last time; CHANGE unfolds them). Quick play is the same screen with a hull picker instead of offers, and **Randomize troopers** for a fresh set of eight candidates, each of a rolled rank.
  - The **KESTREL** tab is the shopping, out of the way of launching: the whole roster with their records, **recruiting** (one of three volunteers), the **armoury** (equip weapons you brought home: click a weapon, then a trooper), the **upgrades** (armour plating, stims, suit cooling, neural link, tracker boost, salvage crew) and the **memorial**.
  - **Difficulty** (remembered for next time):
    - **Enemies:** few, normal, many or swarm (0.6x to 1.9x the hostiles aboard).
    - **Strength:** weak, normal, tough or brutal (0.7x to 1.8x their health, 0.7x to 1.5x their damage).
    - **Ship size:** small, medium or large, within the hull class's own range. Large ships are longer, have an extra deck and carry more hostiles to fill them.
    - **Hordes:** off, rare, normal or often. Off means no horde aboard; Often means less noise brings it, and it nearly always comes. The Enemies setting scales the horde too.
- **Choose a derelict:** one of three offers of three different hull classes, each with a size, modifiers, a pay multiplier and the story its seed tells. Modifiers include *Infested*, *Blackout*, *Treasure hauler*, *Armoury ship*, *Distress call*, *Hive ship*, *Restless* and *Fuel leak*; each class favours some and never carries others (no *Treasure hauler* corvettes). No streaks: one offer is always plain, one has a twist, one has two, and the classes and modifiers of the last few runs come up less.
- **Board:** the squad walks from the docked Kestrel through the boarding tube into the airlock. The lock cycles behind them.
- **Debrief:**
  - **Payout:** recovered credits, sold salvage, contract pay and rescue bounties. A wipe keeps only 25% insurance.
  - **Timeline:** the notable lines of the ship's log, timed - who went down and when, what was found, what woke up.
  - **XP and rank:** from kills, survival and the objective. Promotions run Private, Corporal, Sergeant, Lieutenant, Captain.
  - **Permadeath:** the dead go to the memorial.
  - **Threat:** every extraction raises the threat level, which brings more hostiles, better loot and better pay.
- **Saving:** the campaign is saved in the browser. Reloading mid-run abandons the operation; there is no save-scumming.

## Hulls (the derelicts)

Every seed is a **hull class** and a number: `CRV-7F2A9B` is corvette 7F2A9B. A bare seed rolls its class (so old seeds still work; they now name the class they rolled). The class sets the ship's shape, where the Kestrel docks, where the command deck is, which rooms it has and where they sit:

| Class | Code | Shape | Dock | Command deck | Rooms of its own |
|---|---|---|---|---|---|
| Corvette | `CRV` | 2 long decks, a wedge | the lower deck, aft | forward, upper deck | missile magazine, barracks, a galley |
| Freighter | `FRT` | 3 decks, stepped | the lower deck, aft | forward, upper deck | holds and stores amidships |
| Liner | `LNR` | 3-4 decks, a block | the lower deck, aft | forward, upper deck | cabins, galleys, hydroponics, medbays |
| Research vessel | `RSV` | 3-4 decks on a long spine | at the waist, a middle deck | forward, on another deck | laboratories, specimen bays, hydroponics |
| Station | `STN` | 5-6 short decks round a core | the ring, a middle deck | in the core, up top | promenades, galleys, hydroponics |

- **Port or starboard:** the Kestrel docks on either side. A starboard dock mirrors the whole ship: the squad boards heading left and the bow is to the left.
- **Zones:** rooms are placed by section - engineering and the reactor aft, the holds amidships, quarters and the medbay forward (on a station, by ring) - and each class caps its rarer rooms (one magazine on a corvette, three labs on a research vessel).
- **The best of five:** the generator lays out five ships for a seed and keeps the one that plays best: the longest way through, with loops to double back by, dead ends for nests, and climbs and stairs on the way.
- **Halls:** some ships have a room two decks tall - a hold, a hangar bay, the reactor - with nothing over it on the deck above, whose rooms sit either side of the void. The walls run the full height, the lamps hang in two rows, and whatever crawls on its ceiling has a long way to drop.
- **Stories:** every derelict tells one, rolled from the seed and the hull (a corvette tends to mutiny, a research vessel to lose containment, a liner to evacuate): where the dead lie and what they carry, whether the medbay welded itself shut, how many nests and survivors, which way the ship's events lean. The briefing reads it off the seed.
- **Briefing:** ship intel names the class and what it is like; the hull picker (AUTO, or any class) rewrites the seed code, and the deploy link carries it.
- **Looks:** each class casts its own tint over the kit (cold blue-grey warship, rusty hauler, warm liner, clinical research vessel, patchwork station), wears its wall tiles its own way, lights its rooms its own colour, and has walls of its own - a liner's cabins, a lab's tiling and jar cabinet, a freighter's container ends, a corvette's weapons racks, a station's shop fronts - and props of its own (missiles on cradles, hydroponics troughs under grow lamps, specimen tanks, lab benches, galley counters, vending kiosks).
- **From outside:** beyond the hull each class has its silhouette against the stars - drives with their burners lit, cargo pods under the keel, a bridge house, a liner's funnel and portholes, a research vessel's dish and boom, a station's solar arrays and berth - placed from the level's own geometry (so a starboard-docked ship is mirrored too), in box geometry that needs no art.

## Troopers: stats and archetypes

Every trooper has eight stats rated 1–10. A 5 is the baseline.

**Ranks.** Five of them, and like gear tiers each has its colour - on the trooper's card, his portrait frame and his name, in the briefing, at Command, at the debrief and in the squad panel in game:

| Rank | Colour | Quick-play candidates |
|---|---|---|
| Private | grey | archetype stats (44 points); about 1 in 3 |
| Corporal | green | +4 points; about 1 in 3 |
| Sergeant | blue | +8 points; about 1 in 5 |
| Lieutenant | purple | +12 points; about 1 in 9 |
| Captain | orange | +16 points (an average of 7.5); about 1 in 20 |

A candidate's extra points go mostly into what his archetype is already good at. In the campaign, troopers earn their rank with XP.

| Stat | Effect |
|---|---|
| **Strength** | Heavy weapons, forcing locks, shrugging off claws. |
| **Speed** | Walking pace (the squad moves at its slowest man), climbing, reloads. |
| **Stamina** | Health and a personal breath bar. The squad only runs while everyone has breath. |
| **Accuracy** | Weapon spread. |
| **Perception** | Reaction time, flashlight reach, awareness radius, spotting. |
| **Intelligence** | Searching, the uplink, stim healing (the squad's tech and medic), hacking. |
| **Nerve** | Making energy last on high alert, composure under attack. |
| **Luck** | Critical hits, a lucky escape from a killing blow, better weapon finds, better odds. |

Archetypes all spend the same points budget, so none is strictly better: veteran, heavy, breacher, marksman, scout, tech, medic, rookie, duelist, brawler and gunner.

Three of them fight differently:

| Archetype | Kit | How he fights |
|---|---|---|
| **Duelist** | Bolt pistol + power sword | A few heavy explosive bolts at range. Anything that closes within reach gets cut down instead, two at a time. |
| **Brawler** | Power fists (no gun) | Never fires a shot. Anything that comes within reach, even clawing the man ahead, takes a blow that staggers it and drives it back, even a brute. The gauntlets block some of every claw. Best on point or as rear guard. |
| **Gunner** | Minigun | The barrels spin up for most of a second before the first round, then a wall of lead (twice the heavy repeater's). Loud, and the squad walks at his slower pace. |

Power-weapon blows land a moment into the swing; Strength makes them hit harder and Speed makes them come quicker.

Stats also decide who does what:
- **Jobs:** the squad's best mind searches crates, works locks and runs the uplink. If that isn't the point man, he steps out of the line and walks up to do it while the others cover.
- **Pace:** the slowest man sets the squad's walking pace.
- **Breath:** the least fit man decides how long the squad can run.
- **Nerve:** a badly hurt trooper with shaky nerve may panic for a moment (firing wild, slow to react), unless a steady squad-mate is beside him.
- **Breaking point:** clawed below a third of his health, a trooper breaks, once until he's patched up past half. His stats weigh which way: low nerve **freezes** (hunkers down, won't fire or move, and the squad won't leave him), quick feet **bolt** (to the back of the line and back the way they came, hiding until it's over), strength and steady nerves go **berserk** (faster, wilder fire at every hostile in sight, shoving whatever gets close). It passes once it's quiet around him for a few seconds, or as soon as a stim or a dressing gets him past half.

**Learning by doing:** during a mission each trooper practises what he actually does:

| Practice | Grows |
|---|---|
| Hits | Accuracy |
| Spotting first | Perception |
| Searches, stims and the uplink | Intelligence |
| Heavy work | Strength |
| Punishment taken | Stamina |
| Running | Speed |
| Close calls | Nerve |
| Lucky breaks | Luck |

At the debrief, practice becomes stat points. They get dearer the better a trooper already is, and cap at his core + 3. The debrief shows what grew and what each trooper is getting better at.

## Standing orders (the doctrine)

The squad acts by the orders set in the briefing, and you can change any of them mid-mission from the orders bar. Switching the route to or from Manual hands it over: the squad holds and waits for your clicks, or sets off on its own.

**Manual** is the player's game, and the default. The squad holds position until you click somewhere to go: a spot on the floor of a room they know, or something in the scene. They go there, then hold and wait for orders again.
- On the way they still handle doors, ladders, fights, stims and flashlights themselves.
- Encounters wait for your choice.
- Clicking somewhere new walks away from an unanswered encounter.
- **Turn around** reverses the line in place.

**Recon**, **Assault** and **Salvage** run themselves: they choose their own route and answer encounters by their orders if you don't (kept for multi-team play).

You can adjust each order yourself:

- **Route:** straight to the cockpit, or sweep the side rooms first. A sweep stops after six minutes. *Greyed out under Manual: the route is yours.*
- **Fire discipline:** cautious, normal or high alert (burns energy - see below).
- **Pace:** stealthy (a quiet crouch-walk), steady (a jog), or fast (a sprint). Fast sprints whenever everyone has the breath: sprinting drains each trooper's stamina slowly (about half a minute from full) and the stops in between barely give it back. Once someone is spent they drop to a jog until everyone is back above half.
- **Loot:** leave it, grab what's on the way, or search everything. *"Search everything" is greyed out under Manual: a squad that only moves on your word doesn't go looking for crates. They still search the ones they pass.*
- **Stims:** early, critical or hoard. The medic uses them.
- **Flashlights:** on, off, or auto (off only while calm in a lit room).
- **Kit:** use it (grenades into a pack or at something big, flares into a dark room with something in it) or save it for your call.

## Gameplay loop (a run)

1. **Advance.** The point man walks in the squad's heading, and the others replay his exact path, including ladders and jumps, spaced along a breadcrumb trail.
   - Each trooper has their own height, gait and pace.
2. **The marines decide.** At doors, ladders, stairs and crates the squad stacks up, then acts by its standing orders: open or turn back, climb or pass, search or leave.
   - A weapon they find goes to whoever gains most, otherwise it is stashed for the ship.
   - **Turn around** sends them the other way for a while, toward unexplored rooms behind them.
   - Dead ends turn the squad around automatically, and the rear trooper becomes the new point man.
   - **Pointing at something** makes it their goal: go through a door, take a ladder, search a crate (even under "leave it" orders), check a terminal, reach a survivor, or shoot a fuel barrel once nobody is in the blast.
   - **Encounters** stop the squad and offer choices in the scene, each done by the best man for it, with the odds shown. If you don't choose within 8 seconds, the standing orders decide.
     - **Sealed weapons locker:** hack the keypad (Intelligence, quiet) or force it (Strength, loud). Success upgrades what's inside; failure trips an alarm or hurts the man forcing it.
     - **Crew terminal:** pull the deck plans (Intelligence), which maps the ship and every cache.
     - **Something in the locker:** if sharp eyes spot a hostile hiding in a container, shoot it first (the loot is lost) or open it carefully (Nerve).
     - **Door controls:** close a door behind you (they have to force it), weld it shut (a charge - nothing gets through), or cut a welded one open (a charge, loud).
     - **Duct vent:** weld it, and nothing comes out of that one again.
     - **Power junction** and **doorway on fire** come with the ship events below.
     - **Sentry turret:** hack it (Intelligence) and it fights for the squad until its ammo runs out. A botched hack locks it out, with an alarm.
     - **Autodoc** (the medbay): a cycle heals everyone and mends the worst wound. One cartridge; save it for later if nobody needs it.
     - **Egg cluster** (in nests): burn it with a flare, shoot it (loud, and one might get out), or sneak past (Nerve: if they stir, they hatch).
     - **Cryo pod:** sharp eyes (Perception) may read what's inside first - a survivor, something hostile, or a sealed cache. Open it, shoot it through the glass, or leave it.
     - **Locked storeroom:** a door off the route that wants a keycard. One of the dead crew lying about the ship carries it; or cut through with a charge. Inside is something worth the trouble.
     - **Sealed medbay:** on a ship that went into quarantine, the medbay welded itself shut from inside; a charge cuts it open.
     - **Weak bulkhead:** a corroded seam the survey marked, in a solid wall between rooms a long way apart by the doors. Set a charge (a charge, loud) and it is a doorway the ship never had - a shortcut for the squad, and for everything else aboard. A blast against it does the same.
   - **Breakables.** Furniture breaks under fire and in blasts, and leaves its wreck. A container smashed open spills what it held: credits, ammo, keycards and kit survive, stims and medkits don't, a good weapon may come out a grade worse, a sealed locker needs no hacking, and whatever was hiding inside comes out hurt. Fuel barrels and gas cylinders explode (chain reactions, a huge noise) and leave the deck burning for a few seconds; a fuse box shot out puts its room in the dark for good.
3. **Stances and drills.** Troopers are **casual** (weapon lowered), **alert** (weapon at the hip) or **engaged** (weapon at eye level), depending on context.
   - **Doors:** #2 kneels to cover the door and the rear man watches behind.
   - **Ladders:** one climber at a time, with the next man covering the shaft and the first man up covering the hatch.
   - **After a fight:** weapons stay up for a few seconds, then someone calls "Clear!".
   - **On the move** the formation is loose. Each trooper has his own pace, the spacing drifts, and stragglers jog to catch up.
     Everyone watches his own sector: point ahead, #2 high (vents, hatches), #3 low (crates, bodies), rear behind. Weapons and flashlights pitch onto what they look at, and the sight cone follows.
     Troopers stop briefly to check vents and bodies. The rear man checks six. The point man pauses at each new room and advances in bounds when something is on the tracker.
     Noises and contacts pull eyes round, and a contact on another deck points weapons at the ceiling or floor. In a firefight the front rank kneels while the rear covers the other way.
   - **Down, not dead.** A killing blow puts a trooper on the deck. There is no clock: he stays down until a squad-mate gets him up (the medic is quickest; a stim gets him up stronger) or until a claw finishes him. Self-led squads go back for him; under Manual, click him. Up again, he carries a wound for the rest of the mission: a bad leg slows him and his climbing, a bad arm spoils his aim and reloads.
   - **Firing drills.** A man running low changes mags while the others are still firing, one at a time, so the squad never runs dry at once. In a lull they top up half-empty magazines. While a squad-mate reloads or is down, the rest cover him with shorter pauses between bursts. Rounds coming in pin a hostile down: slower, and no pouncing (a heavy pins hardest).
   - **The shove.** One clawing at a trooper who can't shoot it (reloading, dry) may get driven back with his weapon, staggered. Strength helps; a breacher does it hard and often. Brutes and the brood mother are too heavy.
   - **Specialists.** The veteran keeps the squad from breaking; the heavy holds the line in Cover (faster, tighter fire); the breacher shoves and gets doors open in half the time; the marksman's round into something that hasn't noticed the squad hits for 2.5x; the scout picks out anything shadowing the squad; the tech welds with his own torch (no charge); the medic carries three field dressings for a lull.
   - **Morale.** Kills, getting a man back up and a dead brood mother lift it; men going down or lost, screams and ambushes wear it down; out of a fight it settles. Steady squads aim and react a little better; shaken ones worse, and panic gets in.
4. **Mental state (fire discipline):**
   - **Cautious:** return fire only.
   - **Normal:** fire at anything that moves, including vermin and survivors nobody has identified yet (friendly fire).
   - **High alert:** weapons up, fastest reactions, every hostile. It burns the squad's **energy** (about a minute of it from full). Kills refill it - every alien a little, every animal more - and so do food and energy drinks found in containers. Out of energy, the squad drops back to normal and goes on alert again once the bar is back to half.
5. **The ship fights back:**
   - It holds a fixed number of hostiles per ship (shown as life signs, its horde included). Clear it for a bonus.
   - Predators sleep - on the floor, up on the ceiling or clinging to a bulkhead - then wake on sight, footsteps, gunfire or explosions.
   - Breeds: **drones** (the baseline), small fast **runners**, **creepers** that live on the ceilings, big slow **brutes** that hit hardest and shrug off stagger, and deeper in **spitters** (keep their distance and lob acid that pools on the deck), **screamers** (a scream wakes every sleeper in earshot and calls more out of the vents; cut it off with a heavy hit) and, now and then, one **brood mother** in the deepest nest, birthing runners while she's awake.
   - Climbers take the high road: up the nearest bulkhead (or a spring straight up), along the ceiling over the squad, then they drop on someone. A breacher blast or a grenade knocks them off; shot dead up there, they fall.
   - **Pack habits.** A climber goes over the squad for the man at the back while a packmate keeps them busy. One woken unseen may shadow the rear and strike when someone reloads or the line strings out. A badly hurt runner or creeper may bolt into the vents and come back out near the squad, healed. Creepers back off from torchlight. Runners come to gunfire from further off. One that reaches a man down may drag him off to a vent: shoot it off him, or he's gone.
   - **Cover and chokepoints.** Aliens take a doorway one at a time and vault what's on the walking line (slowly, exposed). A trooper crouched behind debris takes spitter acid on the cover.
   - **Ship events** (none on a clock): a deck's **power fails** when the squad gets there (lights out, short sight, sharper alien hearing) until someone resets its junction; a **doorway catches fire**, blocking squad and aliens alike until it's put out, braved or routed round; a **distress call** puts a survivor deep in the ship, with a beacon on the tracker.
   - A pacing director sends vent ambushes.
   - **The horde.** At most once a ship, and maybe not at all: noise brings it. Every shot, blast, door and sentry gun heats the ship up, and so do screams, power failures, fires, ambushes and hatchings; it cools off in the quiet. While the ship is hot, each second there's a chance it comes - a loud squad meets it sooner. Then the tracker lights up: a 10-second countdown while the squad holds where it is, then a swarm - twenty-odd at threat 0, more with the threat and the Enemies setting, mostly runners and drones - pours out of the vents on both sides, all within a few seconds. Its hostiles are its own: the life signs count them from the start, but the ordinary ambushes never draw on them. **Defend** is the answer: two sentry guns set down either side of the squad, each with its own belt. They stay where they're put and keep firing at anything that comes near, with the squad there or not. Under the Kit order *use it* the squad sets them up by itself during the countdown.
   - Fuel barrels explode, and blasts chain between barrels.
   - **The kit:** three welding charges, three frag grenades and three flares (a flare lights its room for the rest of the mission, and creepers hate it). The squad carries one **Defend kit**; more are found in containers like other loot (one beside the way to the command deck, one more somewhere aboard).
   - The motion tracker pings anything that moves.
6. **Loot and people:**
   - Four weapon rarities (standard, rare, epic, legendary) with rolled bonuses.
   - Treasure salvage.
   - Food and energy drinks (energy for high alert).
   - Survivors to identify and send back to the Kestrel.
7. **Finish.** Reach the command deck and hold it while the navigation uplink completes.

## Architecture

```
src/
  core/      loop (fixed 60 Hz step + interpolation), seeded RNG streams, config, events, input, asset loader
  gen/       procedural ship: hull classes (shape, dock, bridge, zones), layout (spanning tree + loops, best of five), room templates, props/loot/vents/actors, mirroring
  nav/       portal-graph route planner, breadcrumb trail
  sim/       world (step order, commands), squad, tactics (stances/drills), awareness (looking around),
             doctrine (standing orders, goals, nudges), encounters, stats (1-10 -> modifiers, practice), aliens (breeds, pack habits),
             critters, survivors, combat/ROE (firing drills), hazards (destructibles), kit (grenades, flares), melee (shoves, specialists),
             morale, sentry (hacked turrets), shipevents, loot, barks, director, traversals
  meta/      campaign profile (roster, XP, upgrades, permadeath, settlement), candidates (archetypes), growth, derelict offers
  physics/   Rapier wrapper: static colliders, doors, kinematic hitboxes, raycasts, debris
  vis/       sight rules (shared by gameplay and rendering), visibility polygons
  render/    view, level builder (kit batching), actors, lights, fog-of-war mask, fx, markers (glows on what can be clicked), camera, post
  ui/        DOM HUD, in-world interactions + encounter cards, minimap/tracker, Command, Briefing and Debrief screens
  audio/     sfx (events -> sounds, the mix, procedural fallbacks), samples (loads the recorded set)
tools/
  blender/   art generators (marine, alien, critter, props, roomkit) + shared bpy library
  run-blender.mjs · check-glb.mjs · shot.mjs (headless-Chrome screenshots)
  dev/balance.mjs (autoplay stats) · dev/threat.mjs (difficulty ladder) · dev/campaign-e2e.mjs (full loop) · dev/flicker.mjs (single-frame visual glitches) · dev/nanhunt.mjs (NaN/Inf pixels) · dev/sfx-levels.mjs (loudness of every sound) · dev/sfx-audit.mjs (every sound in a real run: fired, dropped, level)
  audio/     fetch-sfx.mjs (download + licence-check sources) · analyze-sfx.mjs (find the events in each) · build-sfx.mjs (cut, level, encode)
tests/       vitest: generation (450 seeds across the five classes), navigation, visibility, simulation
```

Key design decisions:

- **The simulation is pure data.** There is no three.js or DOM code under `src/sim` or `src/gen`, so the whole game runs headless under vitest. Autoplay tests play complete ships to the win screen.
- **Determinism.** Every system draws from its own seeded RNG stream. The same seed always produces the same ship and the same simulation.
- **Movement is scripted, not physics-driven.** Characters move along the navigation graph. Rapier only answers "what does this ray hit", so the rules for who can see and who can shoot always agree.
- **The room graph drives navigation.** Movement inside a room is one-dimensional. Portals (doors, ladders, stairs, and vents for aliens) connect rooms.
- **Constant light count.** Flashlights and pooled lamp and muzzle lights are reassigned each frame rather than created, so shaders never recompile mid-game.
- **Fog-of-war.** Visibility polygons are drawn into a world-space mask texture with MAX blending. A persistent copy of the mask remembers explored areas, and a darkness pass applies it after the scene renders.

## Sound

Every recording in `public/assets/audio` is **CC0** (public domain) except where [CREDITS.md](public/assets/audio/CREDITS.md) says otherwise; each file is credited there, and `tests/audio.test.js` keeps the credits complete. The sources are:
- Freesound: the hull ambience and drone, doors, the airlock, gunfire, reloads, the xenomorph hisses and growls, screeches, explosions, footsteps, the motion tracker, the alarm, sparks and computer beeps;
- Kenney's sci-fi, impact and interface packs;
- the OpenGameArt 50 sci-fi and 80 creature packs;
- `tools/audio/src`: recordings kept in the repo rather than fetched. The carbine's fire is the M41A pulse rifle clip there (freesound_community on Pixabay, Pixabay Content License): its sustained chatter is looped for as long as a marine's rounds keep coming, then one of its burst ends plays (`FIRE_LOOP` in `src/audio/sfx.js`). The sentry guns still fire the single M4A1 shots.

All 33 sounds come to 2.6 MB of MP3 (about 3 variations each, never the same one twice running). They load after the first click, key or stick input. Until a sound has loaded, and for any that is missing, the old procedural version plays. The stingers and the stim are still synthesised.

- **Hear them:** `/sfx.html` plays each game event exactly as a run does. It switches between recorded and synth, and lists every take with its source.
- **Mix:** `MIX` in `src/audio/sfx.js` sets the level of each sound. `node tools/dev/sfx-levels.mjs` measures them against the synth versions. `node tools/dev/sfx-audit.mjs` plays a ship in real time and accounts for every sound: events, sounds played, drops, and each gun's level in the mix.
- **Change the set:**
  1. `node tools/audio/fetch-sfx.mjs` downloads the candidates into `tools/out/sfx-src`. It checks every Freesound page for the CC0 licence first.
  2. `node tools/audio/analyze-sfx.mjs` finds the separate events in each file (single shots, steps, hisses).
  3. Edit `SELECTION` in `tools/audio/build-sfx.mjs`, which sets the takes, cut points and loudness.
  4. `node tools/audio/build-sfx.mjs` cuts, mixes to mono, matches loudness, crossfades the loops and writes the MP3s, `manifest.json` and `CREDITS.md`. `--only fire_carbine,fire_carbine_tail` rebuilds just those and keeps the rest of the set (a sound cut from `tools/audio/src` needs nothing fetched). `CHROME=/path/to/chrome` picks the browser it decodes in.

## Art pipeline

See [tools/blender/README.md](tools/blender/README.md) for the full asset contract. In short:
- Each model is built from bevelled bmesh primitives.
- Colour comes from vertex colours.
- Characters are rigidly skinned: each armour piece is bound 100% to one bone.
- Animation clips are keyed in script and exported as one GLB per asset family.
- On the move a trooper's legs always walk or run at the speed he's going. A reload, a shove, a hand signal or a burst plays on his upper body only (the clip split at the hips), so nobody glides along the deck in a standing pose.
- The bolt pistol and minigun share the other weapons' grip points; the power sword rides the left hand and the power fists both hands. The minigun's barrel cluster has its own bone, which the game spins. Power fields use the emissive `M_Power` material.
- `npm run assets` needs Blender. Where only Python is available, `pip install bpy` (Blender as a Python module) and `BLENDER=tools/bpy-blender npm run assets` run the same scripts (`BPY_PYTHON` picks the Python that has `bpy`). The module exports without meshopt compression, so the build then packs each GLB with `gltfpack` (a devDependency), keeping node names, materials and float precision. Previews also need EGL (`libegl1`, `EGL_PLATFORM=surfaceless`).
- Room pieces are merged per room at load time, keeping draw calls low.
