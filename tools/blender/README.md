# Blender art pipeline

All game art is generated by Python scripts run in headless Blender 5.2. Nothing is hand-modelled and there are no sprite sheets: every model is low-poly geometry with vertex colours, exported as GLB with skeletal animation clips.

```
npm run assets                     # build everything -> public/assets/models/*.glb + manifest.json
npm run assets -- marine --preview # one asset + contact sheet in tools/out/previews/
npm run check-glb                  # validate clips / sockets / nodes against the metadata
```

Open `viewer.html` in the dev server (`npm run dev`) to inspect models and clips with game lighting.

## Library (`lib/`)

| module | purpose |
|---|---|
| `common.py` | scene reset, `material()`, `paint()` (per-face jitter + fake AO), `weather()` (battle wear: chipped bevel edges, grime rising from the boots, mud, scorches, soot stains), bmesh primitives (`box`, `cyl`, `sphere`, `prism`, `merge`; bevelled faces are tagged `edge` for `weather()`), `part()` → coloured object with optional 100% bone weight, `join()` |
| `rig.py` | `build_armature()` (every bone's local X = world +X), `skin()` (join rigid parts + armature modifier), `socket()` (empty parented to a bone) |
| `anim.py` | `Clip(arm, name, frames, loop, **meta).cycle([...poses]).done()` - keys every bone at every key, stashes to NLA |
| `export.py` | `export_glb()`, `write_meta()` (sidecar JSON merged into the manifest), `bounds()` |
| `preview.py` | Workbench contact sheets (`contact_sheet`) and stills (`still`) |

### Conventions

- **Units**: 1 Blender unit = 1 m. Blender Z is up. glTF export converts to Y-up: *Blender (x, y, z) → three.js (x, z, −y)*.
- **Facing**: characters face **−Y** in Blender (towards a front-view camera), i.e. **+Z in three.js**. The game rotates them to face ±X with a slight 3/4 turn toward the camera.
- **Side-view game camera** looks from three.js +Z (Blender −Y) with an orthographic projection. **Front faces (−Y in Blender) are what the player sees**; tops and backs are rarely visible.
- **Rigid skinning**: each part is weighted 100% to one bone, then everything is joined into one mesh (one draw call per character).
- **Pose rotations**: all bones have local X = world +X, so rotating +a° about X swings a bone's tip *up → forward (−Y) → down → back (+Y)*. For example, thigh −25 steps forward, shin +40 bends the knee, and upper arm −70 raises the arm forward.
- **Clips** are in place (no root motion). Stride speed at 1× playback goes in the clip meta (`speed`, m/s) so the game can match foot speed to movement.
- **Materials** (names matter to the engine):
  - `M_Base`: vertex-coloured body.
  - `M_Accent`: vertex colours kept light/neutral; the engine multiplies them by a per-marine squad colour.
  - `M_Glow`: emissive (eyes, visor, lamps, screens); it blooms in game.
  - `M_Power`: pale-blue emissive power fields (the power sword's edges, the power fists' coils).
- **Colour** lives in the `Color` corner attribute (`paint()`). Keep palettes dark and desaturated; let emissives and flashlights carry the contrast. The marines are weathered on top (`weather()` on every part but the glows): grim and battered, not factory-fresh.

## Asset contract (the engine depends on these names)

### `marine.glb`: power-armoured squad trooper
- Height about 2.1 m, feet at z = 0, centred on x = 0, facing −Y. The build is grimdark power armour: massive studded pauldrons riding high, a tall gorget the helmet sits down in, a winged-chevron unit badge, red-wax oath seals with parchment strips, a backpack with exhaust stacks - all battered and grimy. (Original designs: no third-party insignia.)
- **Stance clips** (loop unless noted). `sim/tactics.js` picks the stance from context:
  - **Casual** (weapon lowered, muzzle about 45° down): `idle_casual`, `walk_casual` (meta `speed`), `run` (`speed`).
  - **Alert** (weapon at hip level): `idle_alert`, `walk_alert` (`speed`), `crouch_alert`, `crouch_walk` (`speed`).
  - **Engaged** (weapon at eye level): `aim`, `walk_aim` (`speed`), `shoot`, `crouch_aim`, `crouch_shoot`.
- **Covering and other clips**:
  - Covering: `aim_up` (covering a ladder shaft above), `aim_down` (kneeling at a hatch).
  - One-shots: `signal` ("clear" hand signal), `reload` (about 2.2 s), `jump` (about 0.65 s), `hit`, `die` (ends lying down), `bash` (the shove), `slash` (a power-sword cut with the left hand, pistol kept up, about 0.6 s; it lands about 0.3 s in) and `punch` (a right power-fist blow from the guard, about 0.47 s; it lands about 0.18 s in).
  - Traversal: `climb` (ladder loop viewed from behind, meta `speed` in m/s vertical).
  - Loops: `interact` (search/reach).
- **Loadouts**. `marine_base` is the shared body. Variant parts are separate skinned meshes on the same armature, named `var_<slot>_<value>`. The engine shows one of each per trooper (`assets.character(name, { loadout })`):
  - `var_helmet_{command,heavy,breacher,marksman}`
  - `var_pads_{command,heavy,breacher,marksman}`
  - `var_pack_{command,heavy,breacher,marksman}`
  - `var_weapon_{carbine,heavy,breacher,marksman,pistol,minigun,fists}`
  - `var_melee_sword` (shown only for a loadout with `melee: "sword"`)

  All weapons share the same grip and fore-end points, so one set of hand-IK poses works for every weapon. The bolt pistol fills only the right fist (the left holds the power sword, bound to `hand.L`). The power fists are gauntlets on `hand.L/R` and cuffs on `forearm.L/R`, with no gun: the hands still hold the gun bone's grips, which reads as a guard. The minigun's barrel cluster is bound to its own bone, `spin` (a child of `gun`, along the barrels), which the engine rotates while it fires. The meta lists `variants` and `loadouts`.
- **Sockets** (empties parented to bones):
  - `socket_muzzle_<weapon>` and `socket_light_<weapon>`: per-weapon barrel tip and flashlight lens. Plain `socket_muzzle` and `socket_light` are the carbine's.
  - `socket_eye`: visor.
  - `socket_head`: about 0.3 m above the helmet, anchors speech barks.
- **Materials**: `M_Base`, `M_Accent` (tinted per trooper by the engine), `M_Glow` (visor lenses, beacons), `M_Power` (power fields).
- **Budget**: base plus one loadout ≤ 6.5k triangles; whole file ≤ 15k.

### `alien.glb`: four-armed hunched predator (original design)
- Hunched height about 1.6 m, length about 2 m, facing −Y.
- Clips:
  - Movement: `idle`, `lurk` (low crouched dormant breathing), `skitter` (fast run, meta `speed`), `climb`.
  - Attack: `leap` (one-shot, about 0.45 s), `attack` (claw-swipe loop, about 0.85 s per swing).
  - Reactions: `hit` (one-shot), `die` (one-shot).
- Sockets: `socket_head`, `socket_mouth`.
- Materials: `M_Base`, `M_Glow` (eyes/gill slits).
- Budget: 5k triangles or fewer.

### `critter.glb`: small six-legged vermin (neutral life form)
- About 0.5 m long.
- Clips: `idle`, `scurry` (meta `speed`), `die`.
- Budget: 800 triangles or fewer.

### `props.glb`: one top-level node per prop, named exactly as below
- Origin is at floor-contact centre (x = 0, z = 0).
- Width along X should match the `w` value below (±10%).

- Interactables have a hinged child node named `<kind>_lid` or `<kind>_door`, with its origin at the hinge. The engine rotates that child about the hinge's local X (lids) or Z (doors) to show it opened.

### Art direction
Reference: dark, grimy derelict-ship interiors; heavily armoured marines with flashlights.
- **Marines**: olive/khaki-green armour (`#3f4a2b` to `#56623a`), brass/bronze trim (`#8a6a2f`), black undersuit joints (`#16181a`), gunmetal rifle (`#2c3034`) with a dark-red casing detail, and red glowing visor lenses.
- **Aliens**: bone-white/ivory chitin plates (`#c9bda0`) over dark violet-crimson flesh (`#3a1c2e`), sickle claws, and small sickly-yellow glowing eyes. **Original designs only**: no Warhammer 40k iconography or shapes (no aquilas, chapter symbols or "genestealer" silhouettes copied), and nothing from the *Alien* franchise.
- **Environment**:
  - Base colours: gunmetal panels (`#2b2f33`, `#353a3e`), rust (`#5a3a22`), grime.
  - Accents: sparse hazard yellow (`#b8912a`), cold white/teal lamps, red emergency lamps.
  - Organic dressing: green slime (`#4d6b2a`).
  - Heavily bevelled industrial shapes, rivets, pipes and cables.
